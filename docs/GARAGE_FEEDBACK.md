existing source worktree contains other integration work; no publication or

## Garage

Neutral orbit input cancelled the native camera tracking flag every frame.
Zero input now leaves the original focus interpolation running. Category
labels sit below the original icon. The common FNG Init loops drive the
Reputation/multiplier alternation; static position keys do not suppress its
RGBA/scale loops. Native4F7430/4F74F0 use texture dimensions for star sizing.
Style_P1 displays the persistent style total.

A bounded component bank is prepared on one lower-priority CPU thread. No
GPU APIs run there. The main thread publishes a completed current-signature
bank and keeps the old resource owner alive through renderer replacement.
Stale banks are discarded. Publication time is logged separately; smoothness
is a hardware acceptance criterion, not implied by asynchronous CPU loading.

Car flares already had original5443F0 corners and colors. Their generic
material lost world.efx's authenticated RGBA Modulate2x operation. A scoped
FE-car sprite branch restores all four lanes. Main-view/capture depth and
occlusion remain explicit acceptance boundaries. Road/race lamp intensity
is not changed by that FE branch.

## Player tyre marks

Tools/wheel_skid_native.py executes complete original587E90 with an explicit
flat height-query hook and a render-submission observer. Emission requires
contact, a non-inhibited wheel, sufficient horizontal hub speed and either
sliding or sufficient normalized friction utilization times load. The native side projection has
a minimum width factor; opacity has its own floor. Surface13 suppresses it.
Material mapping and width factors come from6EF2D0, stride148. Materials
without a skid texture do not leave marks. CarTypeInfo wheel+14 supplies
actual tyre width. nfsu_race_skid_tests pins original outputs and break cases.

Original5894E0 coalesces short/straight input and limits segment length.
Original40BE70 initializes RGB128;589810 halves stored endpoint alpha and
world.efx restores its RGBA scale. Original textures SKID_ROAD, SKID_DIRT,
SKID_GRASS are loaded read-only. Ground-edge height is adapted from the
copied contact plane, rather than two extra physics queries per wheel.

The port uses a bounded player-only ring, breaks on air/reset/material/gaps,
and submits three material batches. Vertex payload is copied into a fenced
double buffer. No allocation or collision query occurs per emitted mark.
Remote selector3 effects, the original full ribbon pool/visibility manager
and its compression are not reproduced. Canonical physics/replay encodings
exclude all diagnostic skid and prop audio inputs. nfsu_race_skid_retail
checks retail assets, stable vertices, actual coordinates and batch bounds.

## Garage live follow-up

The r21 owner capture showed slow background bank preparation. The room is
now an immutable shared lease across banks; alternate models prepare only
car/shadow/neon/glow commands. A bank shares the read-only source car files
while it is built, then releases those files before publication. Main-thread
GPU ownership and old command lifetimes remain explicit.

CareerGarage owns the preview signature and variant mapping used by both
Switch and the live garage diagnostic. The diagnostic navigates actual
menus through preview, confirmation, purchase and parent restoration. It
compares drawable geometry/skin payload rather than debug names, whose
race-car prefix differs between base and alternative command assembly.

Native rim and generic garage target setters are exercised by
frontend_garage_motion_native.py. The existing road consumer supplies smooth
acceleration and wheel rotation. No arbitrary rotation speed is added.

FE neon uses a generic ground shader; racing neon uses the terrain-projected
shadow shader. The generic path now consumes the same packed color marker.
The FE diagnostic renders that live draw with the current explicit camera,
not the old static camera. A fixed-camera/time alpha-off comparison checks
that it contributes floor pixels. Compiled shader and hardware checks remain
separate; a command existing is not proof of visible light.

The old skid telemetry supplied velocity slip to wheel+168. Original587830
publishes normalized force demand/limit there. The existing force limiter
now exposes that output-only value; tyre forces and canonical replay bytes
are unchanged. wheel_skid_usage_native.py and the race skid test cover the
producer as well as the already verified587E90 consumer gates.

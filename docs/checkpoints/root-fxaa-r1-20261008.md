Switch race-only build option NFSU_RACE_FXAA defaults OFF. This candidate uses
ON, tag fxaa-r1. Enabled only for presented race-environment scenes, not menus,
CPU/reference captures or other diagnostic executables. Current race resolution
remains 960x540, then the existing linear upscale to 1280x720. Native-size HUD
is drawn last and never enters the FXAA input. A native-resolution race uses a
separate scene input and writes FXAA directly to the presentation image.

The GLSL independently expresses FXAA edge orientation, contrast rejection,
perpendicular pixel shift and subpixel reconstruction. Search is bounded to
eight samples in each direction; subpixel strength is 0.5. This is not MSAA,
not a 2x mode and not claimed to reproduce an original NFSU effect or an exact
NVIDIA quality preset. Algorithm reference:
https://developer.download.nvidia.com/assets/gamedev/files/sdk/11/FXAA_WhitePaper.pdf

Each frame slot has distinct input/output images. Clamp-to-edge linear sampling
and a render-to-texture barrier precede the filter. Existing upscale completion
and final GPU timestamps include the filter cost. Two additional low-resolution
color outputs increase GPU allocation; actual Switch allocation and cost remain
unmeasured. No physics, camera, distance or reflection-cadence change.

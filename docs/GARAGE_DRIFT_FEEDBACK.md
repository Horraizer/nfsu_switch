# Garage paint, upgrade badges and Drift Track 2

The supported original is the authenticated US PC 1.4 executable. Original
data and code witnesses are read-only.

- Rims: 5A9A90 and 5A9AF0 select the installed rim family's WHEEL and
  WHEEL_INNER_MASK textures. 5AA680/5AA800 blend the selected color through
  the mask, keeping source alpha. The stock-scene path now applies that
  composition once per prepared painted variant. A missing texture or mask
  keeps the base wheel available. Changing two swatches with the same
  material is checked in the real resident garage preview and purchase flow.
  The retail texture tables supply a matching source and mask for every
  aftermarket texture family in the catalogue.
- Engine: 50C5F0 selects the engine mesh associated with the installed
  engine package for the hood-open preview. The Civic stock and Street
  engine records share both model hashes and use the static CIVIC_ENGINE
  texture. The Pro and Extreme models use the runtime skin. The preview
  and purchase check verifies distinct engine pixels for two accent colors
  on both models. No new tint is synthesized for a stock mesh without a
  paint region.
- New parts: the win handler 5A0DC0 calls 5A3F00 for the winning event and
  stores its result at career+1388. 5A4420/5A4480 select the first reward in
  the selected category, and 5048E0 shows the original browser sprite for
  the selected new item. Garage and package entries now reflect that event
  and the sprite samples the original repeating color track. Save schema11
  retains the latest win across a reload; prior schemas open with no badge
  context and get byte-exact rollback slots on upgrade.
- Drag boost: 4A13A0 and 4A1460 distinguish the drag gauge's wrapped arc
  from the ordinary race arc. The needle uses the original drag angles
  with the existing normalized boost, with no changes to engine torque.
- Drift: see DRIFT_SCORING.md for the event 13 zone counter and native
  award comparison. Timing keeps the highest lap even during a backwards
  crossing. The original player slip guard is applied at the published
  owner-state boundary.

PC checks: nfsu_garage_paint_retail, nfsu_original_feedback_tests,
nfsu_original_feedback_retail, nfsu_drift_state_retail and
nfsu_drift_hud_retail. The original wheel, angle and drift fixtures are
generated by tools/original_feedback_native.py. The drift fixtures specify
the same RNG seed and zone visits on both sides; visual feel and naturally
driven results still require matched original and console runs.

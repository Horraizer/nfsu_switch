# November 28 playthrough build

In Underground, a magazine award now opens a notice and a selection list.
Press A on an issue to see the cover. B returns to the list and restores
the garage camera. The album supports both columns and the final partial row.

Ordinary traffic now uses the original brake-light threshold. Small pedal
adjustments keep the tail lamps at their cruising brightness. Civilian cars
can still tap the brakes several times in succession, as in Cross-town Hustle
in the GameCube original.

Since R99-R72, this build also includes changes to rival starts and braking,
Race Over timing and finish cameras, route arrows, car shadows, wheel motion
on the starting grid, water spray, landing effects and LAN snapshot playback.

## Install

Extract `nfsu-switch-v0.2-playthrough-20261128-sd.zip` to the root of the SD
card. For an existing installation, replace
`sdmc:/switch/nfsu-switch/NFSU_switch.nro`. The game reads data from your own
PC 1.4 USA copy under `sdmc:/nfsu/`. Launch through full-memory Homebrew Menu.
See [Getting started](GETTING_STARTED.md) for the directory layout and controls.

## Verification

The focused magazine and traffic tests passed in both desktop configurations,
including comparisons with the original game. The Switch packaging and embedded
shader tests passed. The wider desktop suites still have known failures in
physics and replay checks. This exact NRO awaits a physical Switch playthrough.
